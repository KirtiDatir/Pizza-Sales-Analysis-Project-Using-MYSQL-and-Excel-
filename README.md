🍕 Pizza Sales Analysis | MySQL & Excel
Analyzed pizza sales data using MySQL to identify meaningful business insights related to revenue, orders, pizza categories, sizes, best/worst-selling pizzas, and peak ordering times. Built an interactive Excel dashboard with KPIs, daily/hourly trends, category & size analysis, and top/bottom seller insights.

Skills/Technologies

MySQL | SQL | Excel | PivotTables | PivotCharts | Data Analysis | Data Visualization

Key insights:
Total Revenue: $817,860
Total Orders: 21,350
Total Pizzas Sold: 49,574
Average Order Value: $38.31
Average Pizzas per Order: 2.32
Identified peak days and ordering hours
Analyzed sales by pizza category and size
Identified top 5 and bottom 5 pizzas by quantity sold
Compared sales performance across different periods using the date filter

📊 Project Highlights
Analyzed sales data using SQL queries in MySQL to identify key business insights.

Identified top 5 best-selling and bottom 5 worst-selling pizzas based on total pizzas sold.

Used the analysis to understand customer ordering patterns and product performance.
